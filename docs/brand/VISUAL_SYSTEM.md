## 1. 컬러 — 60 / 30 / 10

| 비율 | 아키타입 | 역할 | Hex | 쓰임 |
|------|----------|------|-----|------|
| **60%** | Everyman | 일상·중립·넓은 면 | bg `#F3F3F1` · ink `#1A1A1A` · surface `#EBEBE9` · border `#E0E0DC` | 배경, 본문, 카드 기본 |
| **30%** | Explorer | 발견·동선·지도 | `#5A6B7D` · soft `#E8EDF2` · deep `#3D4A57` | 사이트 전역 accent(CTA·링크·아이브로우·활성) |
| **10%** | Hero | 의지·행동 | `#E4572E` · soft `#FCEDE7` · deep `#C2410C` | **`/register` 등록 허브** 배너·진행 칩·권장 카드·primary CTA |

**이유**
- Everyman 60: 문턱 낮은 “동네” 감각 — 튀지 않는 스톤 중립.
- Explorer 30: 길을 찾는 슬레이트(하늘·지도) — 초록 대신 발견 톤.
- Hero 10: 행동 촉구용 엠버 — 공급자 등록 화면에만 집중해 사이트 전체가 공격적으로 보이지 않게 함.

**피하기:** 퍼플 글로우, 이끼 초록 전면 accent, 크림+테라코타+세리프 세트.

토큰: `--everyman-*` · `--explorer*` · `--hero*` (`globals.css` `:root`)  
등록 페이지는 `.register-page { --accent: var(--hero); }` 로 로컬 오버라이드.

## 2. 폰트

| 역할 | 폰트 | 근거 |
|------|------|------|
| UI / 본문 / 한글 헤드 | **Pretendard** | 최근 KR 웹 표준에 가까운 산세리프 |
| 영문 브랜드 (OOOF. 등) | **Poppins** | 기하학적인 O 반복과 마침표가 선명한 라틴 워드마크 |

Noto Serif KR는 사용하지 않음 (고풍·정석 인상).  
대안 후보였던 Noto Sans KR / Spoqa는 Pretendard fallback 스택에만 둠.

### 워드마크 표기

- 기본형은 마침표를 포함한 **`OOOF.`**
- `O O O F`처럼 임의로 띄어 쓰거나 `Ooof`, `ooof`로 표기하지 않는다.
- 첫 방문 설명·About·제안서에서만 `Olly Olly Oxen Free`를 병기한다.
- 작은 UI에서는 정식 명칭을 펼치지 않고 `OOOF.`만 사용한다.

## 3. 보이스 앤 톤 큐 (3)

### Cue A — Everyman · 「동네처럼」
장소·시간·행동. 어린 시절 동네 놀이의 친근함으로 문턱 낮추기.

### Cue B — Explorer · 「울타리 밖으로」
찾기·발견·동선. “지금 갈 수 있는” 숨은 전시를 구체적으로 보여 주기.

### Cue C — Hero · 「의지가 길을 연다」
등록·작가면. “나와도 됩니다”라는 부담 낮은 초대 + 구체 행동 CTA.

|------|--------|
| 홈·지도·검색 | A + B |
| `/register` | C (+ A 단계 안내) |
| `/for-artists` | A + C (색은 Explorer 유지, 카피만 Hero) |

## 5. 꾀꼬리(Oriole) 활용 원칙

꾀꼬리는 **OOOF.의 정식 로고가 아니라 한국적 DNA를 전달하는 보조 자산**이다.  
공유해도 되는 것은 **동물(꾀꼬리)이라는 개념**까지다. MLB Baltimore Orioles의
캐릭터·로고·배색·야구 모티프와 **시각적으로 닮거나 연상되면 안 된다.**

| 사용 가능 | 사용 금지 |
|-----------|-----------|
| “못 찾겠다? OOOF.” 캠페인 | 정식 명칭을 `Olly Olly Orioles Free`로 표기 |
| 동네별 발견 프로젝트 이름 | 모든 페이지 헤더·버튼에 상시 노출 |
| 에디토리얼 화자·SNS 가이드 | 실제 작가·공간을 사냥감처럼 묘사 |
| 온보딩 도움말 캐릭터 (추상화된 자체 디자인) | MLB Orioles 팀 로고·마스코트·유니폼·야구공·주황/검정 팀 배색 연상 |
| 지도에서 숨은 장소를 알려 주는 작은 신호 | 유아용 캐릭터처럼 과도하게 귀엽고 복잡한 표현 |
| 한국 꾀꼬리의 생태·노래를 은유하는 카피 | 기존 구단 캐릭터의 자세·눈·모자·글씨체를 참조·변형 |

캐릭터를 만들 경우:

- 역할: 숨은 전시를 먼저 발견해 **알려 주는 길잡이**.
- 성격: 호기심이 많고 담백하며, 떠들기보다 정확한 정보를 건넨다.
- 형태: 사실적 새 일러스트나 팀 마스코트형이 아니라, **점·부리·날개·지도 핀**을
  기하학적으로 추상화한 **OOOF. 전용** 형태.
- 색: **기존 Explorer slate + Everyman ink**만 사용. 실제 꾀꼬리의 노란색은
  캠페인 한정 보조색으로만 검토하며, MLB식 주황/검정 대비는 쓰지 않는다.
- 검수: “이 캐릭터만 보면 Baltimore Orioles가 떠오르는가?” → 떠오르면 폐기.

## 6. 모션 원칙

1. **숨김 → 드러남** — 카드·핀·이미지가 하나씩 나타난다.
2. **점 → 길** — 흩어진 스폿이 코스 선으로 연결된다.
3. **외침 → 응답** — 질문과 답변, 등록과 공개의 상태 전환을 짧게 보여 준다.
4. 사용자를 놀라게 하는 갑작스러운 점프·깜박임·과도한 바운스는 피한다.
