# 노출·홍보 채널 플레이북

> [GTM.md](./GTM.md)의 Phase 2(Launch & Bootstrap)를 **주 단위 실행**으로 내린 문서.
> GTM은 "무엇을/왜", 이 문서는 "이번 주에 무엇을 어떤 순서로".
> 아웃리치 문구는 [OUTREACH_EMAILS.md](./OUTREACH_EMAILS.md) · [OUTREACH_SCHOOLS.md](./OUTREACH_SCHOOLS.md) 사용.

---

## 0. 원칙 세 가지

1. **채널은 한 번에 하나만 연다.** 4주 검증 → 유지/폐기 판단 → 다음 채널.
   동시에 다섯 개를 열면 어느 채널이 먹혔는지 알 수 없고, 혼자서는 전부 방치된다.
2. **콘텐츠는 제품에서 나온다.** 새로 쓰지 말고, 이미 만든 덱·코스·전시 페이지를
   캡처·요약해서 내보낸다. 콘텐츠 제작이 제품 작업과 분리되면 지속되지 않는다.
3. **모든 외부 링크에 UTM을 붙인다.** 안 붙인 링크는 없는 채널과 같다(§4).

## 1. 기본 실행안 — 앵커 행사가 없는 주

홍보를 큰 행사에 걸면, 행사가 지나간 뒤에는 할 일이 사라진다.
**평상시에도 돌아가는 최소 단위를 먼저 만들고**, 행사는 그 위에 얹는다(§1.2).

### 1.1 첫 4주 (채널 하나 = 카카오 또는 네이버 블로그 택 1)

| 주 | 할 일 | 산출물 |
|----|-------|--------|
| 1주 | 동네 하나를 정해 코스 덱 2개 발행. 채널 1개 개설 | 공유 가능한 URL 2개 |
| 2주 | 같은 동네 콘텐츠 2건 + 작가·공간 아웃리치 40건 | 채널 첫 유입, 공급 회신 |
| 3주 | 코스에 들어간 카페·갤러리에 QR 제휴 제안 2곳 | 오프라인 유입 1개소 |
| 4주 | UTM 지표로 채널 판단 → 유지/폐기, 다음 동네로 복제 | 판단 근거 |

**동네 하나에 집중한다.** 서울 전체를 얕게 덮으면 어느 코스도 "지금 갈 만한" 밀도가 되지 않는다.

### 1.2 행사는 상시 역량으로 — 리드타임 3주 규칙

컬처픽이 삼청나잇·키아프 기간에 사용량을 얻은 것은 기능이 아니라 **타이밍**이었다.
다만 타이밍은 당일에 만들 수 없다. **행사 3주 전에 준비를 시작해야** 그 주에 쓸 것이 있다.

| 시점 | 준비 |
|------|------|
| D-3주 | 행사 권역(동네) 코스 덱 2~3개 확정. 부족한 전시·장소 데이터 채우기 |
| D-2주 | 전용 링크 하나 정하고 UTM 확정. 인쇄물(QR 엽서) 발주 |
| D-1주 | 콘텐츠 예약 발행. 작가·갤러리 DM 사전 발송 |
| 행사 주 | 오프라인 배포 + 채널 푸시. 신규 개발·데이터 입력은 하지 않음 |
| D+1주 | 유입 지표 회고, 다음 행사에 재사용할 템플릿 정리 |

**앵커 후보 (연 단위로 반복되는 것만 적는다)**

| 시기 | 행사 | 성격 |
|------|------|------|
| 9월 초 | 키아프 서울 · 프리즈 서울 · 서울아트위크 | 관객 수요 최대. 2027년부터 프리즈는 DDP → 동대문·을지로 권역 데이터 필요 |
| 9~10월 | 갤러리 나잇(삼청·한남·청담) | 동네별 야간 코스와 궁합이 가장 좋음 |
| 11~12월, 2월 | 미대 졸업전시 시즌 | 공급(신진 작가) 확보. [OUTREACH_SCHOOLS.md](./OUTREACH_SCHOOLS.md) |
| 봄·가을 | 아트페어·아트북페어, 지역 축제 | 공급 우선, 관객은 부수적 |

> 다음 앵커까지 시간이 남아 있으면, 그 기간은 **공급 밀도**에 쓴다(§2 P1). 밀도 없이 맞은 행사 주는 유입이 이탈로 소진된다.

## 2. 채널 우선순위

노력 대비 효과 순서. **위에서부터 하나씩** 연다.

### P0-1. 카카오 (컬처픽 벤치마크)

컬처픽의 `@컬처픽` 챗봇을 그대로 따라가면 개발·운영 부담이 크다. 두 단계로 나눈다.

| 단계 | 형태 | 비용/부담 | 언제 |
|------|------|-----------|------|
| 1단계 | **카카오톡 채널** 개설 + 주 1회 "이번 주 서울 전시" 메시지 | 무료(발송 건수 과금 주의) | 지금 |
| 1단계 | **오픈채팅방** "서울 동네 전시 같이 봐요" 운영 | 무료 | 지금 |
| 2단계 | 카카오 i 오픈빌더 시나리오 챗봇("서울 전시" → 코스 추천) | 무료 티어 + 개발 시간 | 채널 친구 200명 이후 |
| 3단계 | 외부 챗봇 SaaS / 외주(자연어·데이터 연동) | 월 10만 원대 ~ 외주 50–250만 원 | 지표가 증명된 뒤 |

**핵심:** 챗봇은 사람이 이미 모인 다음에 의미가 있다. 1단계 없이 2단계로 가면 빈 봇이 된다.

### P0-2. 네이버 (검색 유입)

우리 도메인은 서치어드바이저에 등록돼 있지만(`public/naverb04e...html`), 신규 도메인이
네이버 통합검색 상위에 올라가는 데는 시간이 걸린다. 그동안은 **네이버 블로그가 우회로**다.

- 주 1편, "성수 전시 추천 / 안국 데이트 코스" 같이 **사람들이 실제로 치는 검색어**를 제목에 넣는다.
- 본문 끝에 해당 코스 URL 링크. 블로그는 유입 통로, 사이트는 목적지.
- 사이트 쪽 SEO(sitemap, JSON-LD, 페이지별 title/description)는 이미 붙어 있으므로 추가 작업 없음.

### P0-3. 인스타그램 · 스레드

- 포맷을 고정한다: **"이번 주 서울 전시 3곳 + 걸어서 이어지는 코스"** 주 1회.
- 릴스는 전시 사진 슬라이드 + 지도 이동 화면 캡처만으로 충분하다(촬영 부담 제거).
- 스레드는 텍스트만으로도 도달이 나오므로, 릴스 대본을 그대로 텍스트로 재사용.

### P1. 공급(작가) 확보 채널

관객 홍보보다 **먼저 코스가 채워져 있어야** 한다(GTM G1 게이트).

| 채널 | 성격 | 메모 |
|------|------|------|
| 뮤움 · 아트허브 | 작가 프로필/공모 게시판 | 홍보글 게시 시 "무료 등록 창구"로만. 판매 보장 금지 |
| 네오룩 | 전시 정보 아카이브, 미술계 실사용 | 전시 정보 정확도가 높아 레퍼런스로도 유용 |
| 미대 졸업전시·학과 조교 | 신진 공급 대량 확보 | [OUTREACH_SCHOOLS.md](./OUTREACH_SCHOOLS.md) |
| 갤러리·대안공간 DM | 전시 데이터 확보 | OUTREACH의 갤러리 DM 템플릿 |

### P1. 오프라인 제휴 (전환율이 가장 높은 채널)

코스에 이미 들어간 카페·갤러리에 QR 엽서·테이블 스탠딩을 둔다.
그들에게도 손님이 생기므로 협상 비용이 낮다. 엽서 앞면은 코스 이름, 뒷면은 QR + 한 줄.

### P1. 뉴스레터·미디어 협업

문화 뉴스레터·큐레이션 계정에 **완성된 코스를 콘텐츠로 제공**한다(원고료 없이 상호 노출).
직접 알리는 것보다 남의 채널을 빌리는 편이 초기에는 빠르다.

### P2. 커뮤니티 침투

당근 동네생활, 대학 커뮤니티, 데이트·전시 카페.
**광고 톤이면 즉시 차단된다.** 실제 다녀온 후기 형식으로, 링크는 본문 끝에 한 번만.

### P3. 유료 광고

GTM 규칙대로 **G1(동네별 공급 밀도) 충족 전에는 열지 않는다.** 빈 코스에 돈을 붓는 셈이다.

## 3. 주간 운영 루틴 (혼자서 유지 가능한 최소 단위)

역량은 지식보다 **반복 가능한 루틴**에서 나온다. 주 5~6시간 기준.

| 요일 | 할 일 | 시간 |
|------|-------|------|
| 월 | 코스/덱 1개 발행 (이번 주 주력 링크 확정) | 90분 |
| 화 | 콘텐츠 1건 (인스타 + 스레드 + 블로그에 같은 소재 재활용) | 60분 |
| 수·목 | 아웃리치 20건 (작가 DM/메일, 갤러리, 공간) | 60분 ×2 |
| 금 | 주말 푸시 (카카오 채널 메시지 / 스토리) | 30분 |
| 일 | 지표 15분 리뷰 (§4) + 다음 주 소재 하나 결정 | 15분 |

## 4. 측정 — UTM 규칙

`?utm_source=<채널>&utm_medium=<형태>&utm_campaign=<주차 또는 행사>`

| 채널 | source | medium |
|------|--------|--------|
| 인스타 프로필/스토리 | `instagram` | `bio` / `story` |
| 스레드 | `threads` | `post` |
| 카카오 채널 메시지 | `kakao` | `channel` |
| 오픈채팅 | `kakao` | `openchat` |
| 네이버 블로그 | `naverblog` | `post` |
| 오프라인 QR | `offline` | `qr_<장소>` |
| 작가 DM/메일 | `outreach` | `dm` / `email` |

예: `https://www.ooof.co.kr/decks/xxx?utm_source=instagram&utm_medium=story&utm_campaign=frieze2026`

**일요일 15분에 볼 것 세 개만:**
1. 채널별 유입 수 (GA 획득 리포트)
2. 유입 후 코스/전시 상세까지 도달한 비율 — GTM North Star("방문 준비 완료 세션")
3. 빈손 이탈(코스 진입 후 즉시 이탈) — 높으면 홍보보다 공급 밀도 문제

## 5. 제품 쪽 선결 과제

홍보를 켜기 전에 제품에서 막혀 있으면 유입이 새어 나간다.

| 상태 | 항목 | 메모 |
|------|------|------|
| 완료 | 공유 썸네일 `og:image` | `public/brand/og-cover.jpg` (1200×630). 루트 + `publicMeta()` 폴백. **배포 후 카카오 캐시 초기화 필요** |
| 완료 | 검색 기반 (sitemap · robots · JSON-LD · 네이버 인증) | 추가 작업 없음 |
| 완료 | 공유 버튼 | `ShareActionButton` — 모바일 네이티브 공유 시트로 카카오톡 전달 |
| 완료 | 재방문 훅 | MY 달력 · 홈 주말 티저 |
| 남음 | 행사 전용 랜딩 (`/frieze` 같은 단일 URL) | 이벤트마다 코스 하나로 보내는 고정 링크 |
| 남음 | 주말 리마인드 알림 | 달력에 담아 둔 코스를 금요일에 메일로 |
| 남음 | 빈손 이탈 이벤트 계측 | 코스 진입 후 무행동 이탈 지표 |
