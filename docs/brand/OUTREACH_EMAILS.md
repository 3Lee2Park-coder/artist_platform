# 작가 아웃리치 · 긍정 회신 메일

슬롯: `{name}` `{spaceOrExhibition}` `{neighborhood}` `{curationUrl}` `{spaceUrl}` `{homeUrl}` `{signupUrl}` `{brand}` `{onePagerUrl}`  
기본 `{brand}` = `Exhibit (가칭)`  
`{signupUrl}` 예: `https://{APP}/auth/signup?redirect=/register/artist`  
`{homeUrl}` 예: `https://{APP}/` 또는 대표 큐레이션 목록 링크

| Type | 언제 쓰나 |
|------|-----------|
| **A** | 이미 큐레이션/공간에 연결되어 있고, 관객과 프로그램을 하려는 작가 |
| **B** | 이미 소개되어 있고, 신진·쇼룸 PR에 가까운 작가 |
| **C** | **공간·전시가 아직 없거나**, 플랫폼에만 관심 있는 작가 — 가치 제안형 모집 |

Type C는 “왜 작가님인지”를 쓰지 않는다. 플랫폼 가치만 제시하고, **스스로 맞다고 느끼는 분**이 회신·가입하도록 한다.

---

## Type A — 관객과 함께하고 싶은 작가

**제목:** `{neighborhood}`에서 관객과 만나는 동네 코스에, 작가님 공간이 포함되어 있습니다

**본문:**

```
안녕하세요, {name} 작가님.

저는 작가의 공간에서 작품과 사람을 직접 만나는
동네 전시를 잇는 플랫폼 {brand}을 준비하고 있습니다.

지금은 신당·성수·안국·망원·북촌 등 동네 큐레이션을 기준으로
공방·쇼룸과 주변 상권을 코스로 연결하고 있습니다.
그중 {neighborhood} 코스에
작가님의 {spaceOrExhibition}이(가) 포함되어 있습니다.

{curationUrl}
{spaceUrl}

{brand}에서는 오픈 스튜디오, 작가와의 대화, 워크숍처럼
관객과 함께하는 시간을 등록하고 예약으로 받을 수 있습니다.
공간·전시·프로그램 등록은 무료입니다.

현장에서 관객과 연결되고 판매로 이어질 수 있도록 돕고,
이후에는 플랫폼에서 결제까지 열 예정입니다.
(현재는 온라인 결제 기능은 없습니다.)

관심이 있으시면 회신 주시거나,
아래 링크로 가입·작가 승인을 진행해 주세요.
승인 후 공간·전시 편집 권한을 연결해 드립니다.

{signupUrl}

감사합니다.
{brand} 팀
```

## Type B — 신진·쇼룸 PR 작가

**제목:** Instagram 밖에서도 발견되도록 — {neighborhood} 동네 코스 안내

**본문:**

```
안녕하세요, {name} 작가님.

저는 개인 작가의 쇼룸·공방이
동네 코스로 발견되게 돕는 플랫폼 {brand}을 준비하고 있습니다.

지금은 신당·성수·안국·망원·북촌 등에서
작가 공간과 주변 장소를 이은 큐레이션을 운영하고 있습니다.
그중 {neighborhood} 코스에
작가님의 {spaceOrExhibition}이(가) 소개되어 있습니다.

{curationUrl}
{spaceUrl}

신진·대학생 작가분들이 쇼룸에서 자신을 PR하고
관객을 만날 수 있는 창구로 쓰시도록,
공간·전시·프로그램 등록을 무료로 열어 두었습니다.
지도로 위치와 방문 방식을 바로 확인할 수 있습니다.

관심이 이어지면 현장에서 연결·판매로 이어질 수 있고,
이후 플랫폼 결제도 준비할 예정입니다.
(현재 온라인 판매·결제는 지원하지 않습니다.)

함께하고 싶으시면 회신 주시거나 가입해 주세요.
승인 후 MY에서 공간 정보를 직접 수정하실 수 있습니다.

{signupUrl}

감사합니다.
{brand} 팀
```

## Type C — 공간·전시 여부와 무관한 모집 (가치 제안)

이미 우리 페이지에 올라가 있지 않은 작가, 아직 쇼룸·전시를 열지 않은 작가,  
또는 **플랫폼 가치를 보고 함께하고 싶은지**만 묻고 싶을 때.

**쓰지 말 것:** “작가님을 선정했습니다”, “작업이 인상 깊어서”, “꼭 모시고 싶어서” 등 개인 선정 사유.

**제목:** 작가의 공간을 동네 코스로 여는 플랫폼 — {brand}

**본문:**

```
안녕하세요, {name} 작가님.

{brand}은 작가의 공간에서 작품과 사람을 직접 만나는
동네 전시를 찾는 플랫폼입니다.

신당·성수·안국·망원·북촌 등에서
공방·쇼룸과 주변 상권을 코스로 연결하고,
관객이 지도와 일정으로 “언제, 어떻게 가면 되는지”를
바로 확인할 수 있게 합니다.

작가는 공간·전시·프로그램을 무료로 등록할 수 있습니다.
오픈 스튜디오, 작가와의 대화, 워크숍처럼
관객과 함께하는 시간도 예약으로 받을 수 있습니다.

현장에서 관객과 연결되고 판매로 이어질 수 있도록 돕고,
이후에는 플랫폼 결제까지 열어갈 예정입니다.
(현재 온라인 결제·판매 기능은 없습니다.)

아직 공간이 없거나 전시를 열지 않은 상태에서도
관심 있으시면 가입·작가 승인부터 진행하실 수 있습니다.
가치가 맞다고 느끼시면 아래 링크로 시작하시거나, 회신해 주세요.

{homeUrl}
{signupUrl}

요약: {onePagerUrl}

감사합니다.
{brand} 팀
```

## 긍정 회신 — 다음 스텝

**제목:** 회신 감사합니다 — {brand} 온보딩 안내

**본문 (A/B — 이미 페이지가 있는 경우):**

```
안녕하세요, {name} 작가님.
관심 가져 주셔서 감사합니다.

다음 순서만 진행해 주시면 됩니다.

1) 가입 및 이메일 인증
   {signupUrl}

2) 작가 승인 신청
   로그인 후 /register/artist

3) 승인 후 저희가 공간·전시 편집 권한을 연결합니다.
   이후 MY에서 사진·방문 정책·프로그램을 수정해 주세요.

요약 안내는 아래 원페이저를 봐 주세요.
{onePagerUrl}

작가님 페이지:
{spaceUrl}
{curationUrl}

궁금한 점이 있으면 이 메일로 회신해 주세요.
15분 정도 화상/방문 일정도 가능합니다.

감사합니다.
{brand} 팀
```

**본문 (C — 아직 공간·전시 없음):**

```
안녕하세요, {name} 작가님.
관심 가져 주셔서 감사합니다.

다음 순서만 진행해 주시면 됩니다.

1) 가입 및 이메일 인증
   {signupUrl}

2) 작가 승인 신청
   로그인 후 /register/artist

3) 승인 후 공간·전시·프로그램을 직접 등록하실 수 있습니다.
   (등록 허브: /register)
   공간·프로그램은 검수 후 공개됩니다.

요약 안내는 아래 원페이저를 봐 주세요.
{onePagerUrl}
미리보기: {homeUrl}

궁금한 점이 있으면 이 메일로 회신해 주세요.

감사합니다.
{brand} 팀
```
