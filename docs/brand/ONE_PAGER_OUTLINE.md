# 작가용 원페이저 목차 (회사소개서 대체)

형식: 1페이지 PDF 또는 Notion 공개 페이지. **투자자용 회사소개서 아님.**  
문장 정본: [PARTNERSHIP_PROPOSAL.md](./PARTNERSHIP_PROPOSAL.md) · 톤: [BRAND_IDENTITY.md](./BRAND_IDENTITY.md)

## 구성

1. **이름** — {brand} (가칭 여부 표기)
2. **한 줄** — 작가님이 더 적극적으로 관객에게 다가갈 수 있는 창구.
3. **공유 비전 (2–3문장)** — 공간·전시를 직접 열고 관객과 이야기하고자 하는 작가와 함께한다. 동네 코스·지도·방문·예약으로 잇는다. 대화·전시는 필수 아님.
4. **작가에게 주는 것**
   - 동네 큐레이션 노출 (신당·성수·안국·망원·북촌)
   - 공간·전시·프로그램 무료 등록
   - 지도·방문 정책·예약·이메일 알림
   - MY에서 직접 수정
5. **관객이 오는 길** — SNS/검색 → 큐레이션 → 지도·상세 → 저장·예약 → 방문
6. **판매·결제** — 현장 연결·판매 가능 / 플랫폼 결제는 로드맵 (현재 없음)
7. **온보딩 3스텝** — 가입·인증 → 작가 승인 → 소유권 연결 후 MY 수정
8. **CTA** — 가입 `{signupUrl}` · 회신 · (선택) 15분 온보딩
9. **예시 링크** — 대표 큐레이션 1 + 작가 공간 1
10. **연락** — 회신 메일 / (선택) 카카오 채널

## 넣지 말 것

- 팀 이력·투자 유치·상세 재무
- 미확정 KPI·보장 문구 (매출·노출·팔로워)
- 긴 기술 스택 설명
- “지금 온라인 결제·판매 가능”
