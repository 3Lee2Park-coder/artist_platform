# 작가용 원페이저 목차 (회사소개서 대체)

형식: 1페이지 PDF 또는 Notion 공개 페이지. **투자자용 회사소개서 아님.**

## 구성

1. **이름** — {brand} (가칭 여부 표기)
2. **한 줄** — 작가의 공간에서, 작품과 사람을 직접 만나는 동네 전시를 찾는 곳.
3. **작가에게 주는 것**
   - 동네 큐레이션 노출 (신당·성수·안국·망원·북촌)
   - 공간·전시·프로그램 무료 등록
   - 지도·방문 정책·예약
4. **관객이 오는 길** — SNS/검색 → 큐레이션 → 지도·상세 → 저장·예약 → 방문
5. **판매·결제** — 현장 연결·판매 가능 / 플랫폼 결제는 로드맵 (현재 없음)
6. **온보딩 3스텝** — 가입·인증 → 작가 승인 → 소유권 연결 후 MY 수정
7. **예시 링크** — 대표 큐레이션 1 + 작가 공간 1
8. **연락** — 회신 메일 / (선택) 카카오 채널

## 넣지 말 것

- 팀 이력·투자 유치·상세 재무
- 미확정 KPI·보장 문구
- 긴 기술 스택 설명
