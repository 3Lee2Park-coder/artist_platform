Interaction rules

화면 상태와 인터랙션 규칙

와이어프레임 구현 시 꼭 반영해야 하는 분기입니다. MVP 프로토타입은 정적 데이터와 클라이언트 상태만으로도 아래 조건을 표현할 수 있습니다.

영역 기본 화면 상태/분기 와이어프레임 반영
SearchBar 날짜, 장소, 큐레이션 여부 검색어 직접 입력 없음 Desktop은 header 중앙 pill, Mobile은 요약 search + filter sheet
CategoryChips 오늘오픈, 이번주, 근처, 회화, 사진, 조각, 복합 당일 활성 전시가 0개인 카테고리 미노출 숨김 규칙을 dashed chip annotation으로 표시
Reservation 전시 상세 CTA 비회원은 인증 이동, 반복 노쇼는 예약 제한 Desktop sticky widget, Mobile bottom fixed CTA
Artist registration 등록하기 CTA 권한 승인 전에는 작가 권한 요청 화면 등록 탭/버튼에서 artistStatus에 따라 화면 분기
Exhibition type 개인 대관형, 갤러리 초대전/기획전, 페어형 초대/기획전은 수정 승인 및 정보 일치 체크 필요 등록 폼 notice와 검토 단계 체크박스 영역으로 표시
Map Naver Map 지도는 보조 탐색 Desktop 40/60 split, Mobile 지도 탭 및 floating card
