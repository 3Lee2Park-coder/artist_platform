Updated structure

Hero CTA, 카테고리 전시, 작품/영상 노출을 반영한 Component Tree

SearchBar 아래 CTA는 전체 홈을 갈아끼우는 필터가 아니라, HeroExhibition의 대표 전시를 바꾸는 큐레이션 탭으로 정의합니다. 전체 탐색은 SearchBar와 검색 결과 페이지가 담당하고, 홈 하단에는 활성 카테고리별 전시와 랜덤 작품, 작가 영상 섹션을 추가합니다.

Hero CTA updates Hero only 회화/사진 전시 섹션 랜덤 작품 노출 작가 영상 1개 업로드 메인 영상 섹션
Product decision

CTA 버튼의 역할 정의

핵심 유저는 홈에서 부담 없이 전시를 발견하고, 관심 있는 전시는 상세/예약으로 이동해야 합니다. 따라서 CTA는 검색 결과처럼 전체 화면을 바꾸기보다 대표 전시를 빠르게 바꾸는 역할이 적합합니다.

Recommended

CTA 클릭 시 HeroExhibition만 변경

오늘오픈, 이번주, 근처, 회화, 사진, 복합 탭을 클릭하면 해당 기준의 대표 전시가 Hero 영역에 표시됩니다. 홈 전체 리스트는 유지되어 사용자가 스크롤 맥락을 잃지 않습니다.

Search remains search

전체 결과 변경은 SearchBar가 담당

날짜, 장소, 큐레이션 여부를 선택하는 SearchBar는 검색 결과 페이지로 이동하거나 결과 리스트를 생성하는 역할입니다. CTA와 역할을 분리해 UX 충돌을 줄입니다.

Category discovery

카테고리 전시는 아래 섹션에서 탐색

전시가 있는 카테고리는 오늘의 발견과 같은 카드 그리드로 아래에 노출합니다. 예: 회화 전시, 사진 전시, 복합 전시.

1

홈 진입

SearchBar 아래 HeroCurationTabs를 확인합니다.

2

CTA 선택

회화/사진/오늘오픈 등을 선택하면 selectedHeroKey가 변경됩니다.

3

Hero 변경

HeroExhibition의 이미지, 전시명, 작가, CTA만 교체됩니다.

4

하단 탐색

아래에서 카테고리 전시, 랜덤 작품, 작가 영상을 이어서 발견합니다.

HomePage

수정된 HomePage Component Tree

HomePage는 검색, 대표 전시 전환, 카테고리별 전시 탐색, 작품 발견, 영상 발견 순서로 구성합니다.

  • <HomePage />
    • <Header /> Logo, desktop nav, mobile menu, profile
      • <FilterSearchBar /> date, place, curation; 검색 결과 이동 담당
    • <HomeHeroModule /> SearchBar 아래 핵심 큐레이션 영역
      • <HeroCurationTabs /> 오늘오픈, 이번주, 근처, 회화, 사진, 복합; active items only
        • selectedHeroKey state 탭 클릭 시 Hero만 변경
      • <HeroExhibition /> selectedHeroExhibition을 받아 image/title/artist/place/period CTA 렌더
        • <HeroMediaFrame /> 대표 이미지를 우선 사용
        • <HeroExhibitionMeta />
        • <ReservationCTA /> 회원 예약/비회원 인증/노쇼 제한 분기
        • <DetailLinkCTA />
    • <DiscoveryGallery /> 오늘의 발견; 기존 섹션 유지
      • <SectionHeader title="오늘의 발견" />
      • <ExhibitionCardGrid />
    • <ActiveCategoryExhibitionSections /> 전시가 있는 카테고리만 섹션 생성
      • <CategoryExhibitionSection category="회화" /> 오늘의 발견과 동일한 카드 UI
        • <SectionHeader title="회화 전시" />
        • <ExhibitionCardGrid />
      • <CategoryExhibitionSection category="사진" />
        • <SectionHeader title="사진 전시" />
        • <ExhibitionCardGrid />
      • <CategoryExhibitionSection category="복합" /> 활성 전시가 있을 때만 렌더
    • <RandomArtworkSection /> 작가가 등록한 작품을 랜덤/큐레이션 조합으로 노출
      • <SectionHeader title="작품으로 발견하는 전시" />
      • <ArtworkMasonryGrid /> Pinterest형 발견 경험
      • <ArtworkCard /> 작품 상세 또는 전시 상세로 이동
    • <ArtistVideoSpotlightSection /> 업로드된 전시 영상 중 일부를 메인에 노출
      • <SectionHeader title="영상으로 만나는 전시" />
      • <VideoSpotlightCard /> video poster, play overlay, exhibition link
      • <VideoCarousel /> mobile에서는 horizontal scroll
    • <NearbyExhibitionSection />
    • <Footer />

Registration

영상 업로드를 포함한 Registration Component Tree

작가는 이미지와 함께 전시 소개 영상을 1개까지 업로드할 수 있습니다. 영상은 전시 상세와 메인 영상 섹션에서 사용할 수 있는 선택 입력값입니다.

  • <RegistrationPage />
    • <ArtistPermissionGuard /> artistStatus approved 확인
    • <RegistrationStepper />
      • <ExhibitionInfoStep />
        • <ExhibitionBasicFields /> title, description, period
        • <VenueAddressField /> Naver Map address
        • <CategorySelector /> 회화, 사진, 조각, 복합 등
        • <ExhibitionTypeSelector /> 개인 대관형, 갤러리 초대전/기획전, 페어형
        • <ExhibitionMediaUploader />
          • <ImageUploader /> 대표 이미지 + 상세 이미지
          • <VideoUploader maxCount={1} /> 작가 업로드 영상 1개 제한
          • <VideoPreview />
        • <GalleryInfoConfirmCheckbox /> 초대/기획전일 때 필수
      • <ArtworkInfoStep /> 작품명, 가격, 재료, 판매 여부
      • <ReservationSettingsStep />
      • <ReviewAndSubmitStep />

Props and data model

추가/수정되는 Props와 데이터 필드

다음 구현 단계에서 컴포넌트 간 계약이 흔들리지 않도록, 이번 수정사항에 필요한 최소 필드를 정의합니다.

Component Key props Behavior Responsive note
HeroCurationTabs tabs, selectedKey, onSelect Hero only 선택된 탭의 대표 전시를 HeroExhibition에 전달 Mobile: horizontal scroll chips
HeroExhibition exhibition, onReserve, onOpenDetail 이미지, 전시명, 작가명, 장소, 기간, 예약 CTA 렌더 Mobile: image first, CTA는 카드 내부 또는 상세 진입 후 sticky
ActiveCategoryExhibitionSections categories, exhibitionsByCategory 전시가 있는 카테고리만 "회화 전시", "사진 전시" 섹션 생성 Desktop: 4-column/3-column grid, Mobile: 2-column or list
RandomArtworkSection artworks, seed, maxItems 작가 등록 작품 일부를 랜덤 노출하고 작품/전시 상세로 연결 Mobile: 2-column Pinterest-like grid
VideoUploader maxCount=1, value, onChange new 승인된 작가가 전시당 영상 1개까지 업로드 Mobile: 파일 선택 후 압축/업로드 진행 상태 표시
ArtistVideoSpotlightSection videos, maxItems new 업로드 완료 영상이 있는 공개 전시를 메인에 노출 Desktop: featured + side list, Mobile: carousel
